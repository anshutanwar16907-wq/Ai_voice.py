# AI Voice Project
Sawal poochho, AI jawab deta hai aur use awaaz me sunata hai.
Gemini API aur gTTS use karta hai.

## Setup
1. pip install -r requirements.txt
2. Gemini API key lo: aistudio.google.com/apikey
3. CMD me chalao: setx GEMINI_API_KEY "your-key"
4. CMD aur VS Code band karke dobara kholo
5. python Ai_voice_project/Ai_voice.py
